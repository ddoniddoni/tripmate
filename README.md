# TripMate

## 함께 정하고, 같은 여행을 기다리는 방법

TripMate는 여행을 떠나기 전, 친구들과 하루 단위의 일정을 함께 완성하는 협업형 여행 플래너입니다.
단체 채팅방에 흩어진 장소, 애매한 시간, 반복되는 “그래서 어디 갈까?”를 하나의 보기 좋은 여행 계획으로 모읍니다.

여행을 만든 뒤 일정을 채우고, 친구를 초대해 같은 화면에서 의견을 더하세요. 누가 무엇을 바꿨는지 따로 전달하지 않아도, 모두가 같은 여행 계획을 바라볼 수 있습니다.

```
여행 만들기 → 하루를 채우기 → 친구 초대 → 함께 확정하기
```

## 이런 여행을 위해 만들었어요

- 친구들과 제주·부산·해외여행을 준비하며 장소와 순서를 함께 정하고 싶을 때
- 여행 전의 설렘은 유지하면서, 일정 조율의 번거로움은 줄이고 싶을 때
- 하루별 동선과 할 일을 한눈에 보이는 계획으로 정리하고 싶을 때

## TripMate에서 할 수 있는 일

### 하루가 보이는 일정 만들기

여행 기간에 맞춰 날짜별 타임라인을 만들고, 장소·시간·카테고리·메모를 더할 수 있습니다. 일정은 수정하거나 지울 수 있고, 같은 날 안에서도 다른 날로도 자연스럽게 순서를 옮길 수 있습니다.

### 지도와 함께 계획하기

타임라인에서 선택한 장소는 지도 미리보기와 연결됩니다. 일정의 흐름과 장소의 위치를 번갈아 확인하며, 하루의 동선을 더 쉽게 그려 볼 수 있습니다.

### 초대 링크로 친구와 함께하기

여행마다 전용 초대 링크를 만들고 편집자 또는 보기 전용 권한으로 친구를 초대할 수 있습니다. 여행을 만든 사람은 참여자를 관리하고, 필요할 때 여행을 정리할 수 있습니다.

### 동시에 맞춰 가는 여행 계획

공동 편집 중인 일정은 연결된 참여자에게 동기화되며, 실수로 바꾼 내용은 실행 취소와 다시 실행으로 되돌릴 수 있습니다. 혼자 계획하다가도, 친구를 초대하는 순간 같은 여행판을 함께 채울 수 있습니다.

## 함께 쓰는 방식

| 역할 | 할 수 있는 일 |
| --- | --- |
| 여행 만든 사람 | 여행 관리, 참여자 초대·관리, 일정 편집 |
| 편집자 | 일정 추가, 수정, 삭제, 순서 변경 |
| 보기 전용 참여자 | 완성된 일정을 확인 |

## 지금 제공하는 경험

- 내 여행 목록에서 새 여행을 만들고 관리하기
- 날짜별 일정 추가·수정·삭제·이동하기
- 일정에 장소, 시간, 카테고리, 메모 남기기
- 초대 링크로 여행에 함께 참여하기
- 공동 일정의 변경 사항 동기화 및 실행 취소·다시 실행하기
- 데스크톱과 모바일 화면에서 여행 계획 확인하기

## 알아두면 좋아요

현재 장소 검색, 지도 미리보기, 경로 정보는 여행 계획 경험을 보여 주기 위한 데모용 지도 어댑터로 동작합니다. 실제 지도·장소·길찾기 서비스 연동은 다음 단계에서 확장할 예정입니다.

초대 링크는 이메일로 자동 발송되지 않으며, 만든 사람이 원하는 채널로 직접 공유합니다. 링크를 연 사람은 로그인한 이메일 기준으로 초대 권한을 받아 여행에 참여합니다.
